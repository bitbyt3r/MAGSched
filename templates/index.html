MAGSched

An authoritative cache of the MAGFest schedule, serving digital signage and other consumers.

Displays

  • Panel displays — broadcast overlay showing the next session in a room
  • Up next displays — the next session in a room
  • Room displays — the session currently running in a room
  • TV guide — scrolling schedule grid of all rooms

API

  • /sessions, /locations, /tracks — JSON collections; each supports /<id> lookups plus limit, offset, sort, reverse, time_range_start, time_range_end, and exact-match filtering on any field
  • /frab — the full schedule as Frab XML (/frab/filtered accepts the same filters as /sessions)
  • /bops-graphics — sessions in a broadcast-friendly format

Full API documentation lives in the project Readme.
